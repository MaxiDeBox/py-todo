# py-todo

Учебный проект: простое веб-приложение на FastAPI + папка `study` с основами Python.

## Требования

- Python 3.12+
- [uv](https://docs.astral.sh/uv/) — менеджер зависимостей проекта

Если `uv` ещё не установлен:

```bash
pip install uv
```

## Запуск приложения

Все команды выполняются в корне проекта.

```bash
# 1. Клонировать репозиторий
git clone https://github.com/MaxiDeBox/py-todo.git
cd py-todo

# 2. Установить зависимости из uv.lock
uv sync

# 3. Запустить сервер разработки
uv run uvicorn main:app --reload
```

После запуска приложение будет доступно по адресу:

- http://127.0.0.1:8000

Интерактивная документация API:

- http://127.0.0.1:8000/docs

## Эндпоинты

| Метод | Путь        | Ответ                          |
|-------|-------------|--------------------------------|
| GET   | `/`         | `{"message": "Hello World"}`   |
| GET   | `/hi`       | `{"message": "Hello User"}`    |
| GET   | `/hi/{who}` | Приветствие с указанным именем |

Пример:

```bash
curl http://127.0.0.1:8000/hi/Alice
```

## Папка `study`

В папке `study` лежат учебные материалы и скрипты по основам Python.
Они не являются частью FastAPI-приложения и не влияют на его запуск.

Запустить учебный скрипт можно так:

```bash
uv run python study/имя_файла.py
```

Если внутри `study` есть подпапки, укажи путь до файла полностью:

```bash
uv run python study/подпапка/имя_файла.py
```

## Структура проекта

```text
.
```
